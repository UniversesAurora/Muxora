# Muxora 窗口系统首个预览

状态：首个交互预览，用于试用并继续改进窗口系统；完整 V0 的业务功能和验收尚未完成。

本阶段交付 Muxora 应用的首个预览。应用通过 WindowSystem 公开 API 组织界面，后续远程业务继续在这套代码中接入。入口为 `src/app/main.cpp`，占位内容由 `src/workspace_host/` 提供，用来试用布局、拖拽、窗口和键盘导航；SSH、SFTP、终端解析、远程桌面与会话管理留在后续阶段。

目前不添加应用 logo；顶部先使用菜单、工具和标题按钮，整体使用紫罗兰色系。窗口模块保留独立 API 与构建边界，复用验证通过测试夹具完成。

## 开发环境

首个预览针对 Windows x64，采用 C++20、Qt 6.12 Widgets，使用 Qt 的 MSVC 2022 64-bit 套件和本机 Visual Studio 2022 的 MSVC 编译器（[ADR 0009](../adr/0009-msvc-toolchain.md)）。脚本自动载入 Visual Studio 的编译环境，并检查编译器不低于 Qt 套件构建时的版本。`-QtRoot` 指向具体套件，例如 `<Qt 安装目录>/6.12.0/msvc2022_64`。

```powershell
pwsh ./tools/build.ps1 -Configuration Debug -Run
```

脚本通过 `-QtRoot` 或 `QT_ROOT` 绑定 kit，也会发现仓库旁的 SDK 和忽略提交的 `.local/sdk.json`。使用显式路径时，例如：

```powershell
pwsh ./tools/build.ps1 -Configuration Debug -QtRoot <Qt 安装目录>/6.12.0/msvc2022_64 -Run
```

| 参数 | 作用 |
| --- | --- |
| `-Configuration Debug` / `Release` | 选择构建类型 |
| `-QtRoot <path>` | 指定本机 Qt kit 目录，覆盖自动发现 |
| `-Test` | 构建后运行自动化测试；包含桌面层时按下文经 `quiet-desktop.ps1 -Elevate` 运行 |
| `-TestLabel <regex>` | 与 `-Test` 一起使用，只运行指定层：`model`、`widget`、`desktop` 或 `model\|widget` |
| `-Run` | 构建后启动 Muxora |
| `-Package` | 收集 Muxora 所需运行文件到本地部署目录 |

下列全量及完整验证命令须先按 [测试范围规则](testing-design.md#1-必须遵守的规则) 取得单独授权。桌面层会显示窗口并发送真实输入，所以经桌面隔离脚本运行：先收起其他应用窗口，测完再恢复。

```powershell
pwsh ./tools/tests/quiet-desktop.ps1 -Elevate pwsh ./tools/build.ps1 -Configuration Release -Test
```

需要单独试用 Release 部署目录时：

```powershell
pwsh ./tools/build.ps1 -Configuration Release -Package
./out/package/muxora-preview/muxora.exe
```

应用构建目标为 `muxora`。当前 Windows 预览的运行依赖、版本及源码来源见 [第三方声明](../../THIRD_PARTY_NOTICES.md)；部署目录保留各项许可证和 Qt 的组件清单。

日常 Release 固定覆盖 `out/package/muxora-preview/`。替换前清除旧程序、运行库、Qt 插件和许可证目录，保留相邻 `data/` 与未知用户文件；如果该目录的程序仍在运行，脚本停止替换并说明占用。Debug、Release、独立模块和外部宿主分别复用固定构建缓存，不按每轮创建新部署目录。

交付到另一台 Windows x64 电脑试用时，使用 7-Zip 便携包：

```powershell
pwsh ./tools/tests/quiet-desktop.ps1 -Elevate pwsh ./tools/package-portable.ps1
```

按交付需要生成便携包时，脚本从 PATH 查找 `7z` 或 `7zz`，也可通过 `-SevenZip` 指定程序路径。Qt 的选择仍使用 `-QtRoot` 或原有自动发现方式。打包先更新固定 Release 部署，再按 `deployment-files.json` 复制运行文件到 `out/package/portable-input/`，不带入部署目录中的私人布局或未知文件。

日常外观试用只需更新便携包时，可运行 `pwsh ./tools/package-portable.ps1 -Validation Archive`。它仍构建 Release、刷新固定部署、检查压缩包并解压核对运行文件，但不执行全量、启动或恢复测试，也不生成这些检查的通过记录。默认 `Full` 包含全量及启动恢复验证，须先按 [测试范围规则](testing-design.md#1-必须遵守的规则) 取得单独授权，再经桌面隔离入口运行。

压缩包固定为 `out/dist/Muxora-preview-windows-x64.7z`，再次生成时覆盖旧包。构建与便携检查记录保存版本、配置、产物路径和实际检查结果，不计算文件哈希，也不生成校验文件；校验代码的适用范围见 [仓库规则](../../AGENTS.md#必须遵守)。

解压整个 `Muxora` 文件夹后双击 `muxora.exe`；运行电脑不需要 Qt、编译器或 PowerShell。包内的空 `data/` 目录启用便携状态，布局保存在 `data/window-layout.json`，可随文件夹一起移动。显式 `--state-dir` 优先；没有相邻 `data/` 的普通构建继续使用系统用户状态目录。

脚本检查 7-Zip 压缩包完整性，再解压到 `out/portable-checks/current/便携包 解压检查/`。在子进程中移除 SDK、编译器和 Qt 插件路径覆盖，分别检查首次启动、本地布局保存与重启恢复；验证记录为 `out/test-results/portable-package.json`。历史打包与验证结果见 [验证日志](verification-log/2026-10.md)。

完整验证入口（同样经桌面隔离脚本运行）：

```powershell
pwsh ./tools/tests/quiet-desktop.ps1 -Elevate pwsh ./tools/verify.ps1
```

该脚本先运行翻译覆盖与反向检查，再运行 Debug / Release 自动化测试，单独配置窗口模块并运行其测试，安装模块后构建 C++ 和 Lua 两个外部宿主夹具，最后移除 SDK 和编译器路径，检查实际部署程序的启动、退出、重启、显隐、全屏、禅模式、底部工具条恢复和 Lua 脚本。入口存在与验证通过分别记录；最近一次结果见下文，历史结果见 [验证日志](verification-log/2026-10.md)。

只需执行 Release 验证时使用 `verify.ps1 -ReleaseOnly`，范围见 [测试入口](testing-design.md#3-工具与统一入口)；默认完整验证命令不变。

完整窗口系统设计见 [窗口模块](../design/window-system-design.md)、[工作区](../design/workspace-design.md) 和 [浮动窗口](../design/floating-window-design.md)。本次以能交互的基础版本为起点，继续根据试用结果修订。

## 当前可试用的功能

单标签拖动的换位阈值已统一，横竖、多行、紧凑置顶与收纳条按同一边缘规则让位，见 [拖动设计](../design/tab-strip-design.md#61-在标签栏内拖动)。

右侧竖向标签提起时保持静置标签的镜像顺序和图标轨道；具体规则见 [标签栏设计](../design/tab-strip-design.md#4-竖向标签栏)。

设置页“界面”和“视图 → 界面”可分别调整字体、字号及全界面缩放，立即作用于已有与新建窗口；字体可填写有顺序的回退列表，行为见 [设置设计](../design/settings-and-commands-design.md#33-界面字体与缩放)。

Windows 的传统字族名称可由系统解析后交给 Qt，设置中可继续填写 `New York`；原始字体列表不会被解析结果覆盖。

菜单栏和弹出菜单在启动恢复、后续创建与运行中修改设置时，都跟随界面字体。

四边非固定收纳条随字体撑开，标题与图标的尺寸会在字体、字体库或界面倍率变化后同步更新。

Windows 界面文字已调整轮廓平滑方式，系统 ClearType 配置保持不变；具体策略见 [字体规范](../design/ui-design-system.md#24-字体)，清晰度仍待试用确认。

浮窗拖入紧凑置顶区时沿用栏内提起样式，避免重复的静置描边；真实观感仍由用户试用。

紧凑置顶区的单行增删使用平面伸缩，拖动仍保留卡片动效，见 [本轮记录](verification-log/2026-10.md#紧凑置顶标签的平面增删2026-10-26)。

紧凑置顶标签的填充与描边已统一轮廓，浮窗拖入同样处理，见 [记录](verification-log/2026-10.md#紧凑置顶方块轮廓一致性2026-10-26)。

竖向悬停外壳增加上下留白，列表与按钮的位置、可用长度保持，见 [记录](verification-log/2026-10.md#悬停栏外壳与逻辑区域分离2026-10-26)。

标签松手后从当前位置平滑落位，相关坐标检查与本轮包见 [记录](verification-log/2026-10.md#标签从松手位置平滑落位2026-10-26)。

标签高度过渡已放慢，旧活动标签仍立即平放，见 [记录](verification-log/2026-10.md#延长标签高度过渡2026-10-26)。

从最大化退出全屏的恢复路径已调整，见 [记录](verification-log/2026-10.md#全屏直接恢复最大化2026-10-26)。

栏末控件按内容边缘对齐，最近一批修改的交付范围见 [记录](verification-log/2026-10.md#栏末控件对齐与本批交付2026-10-26)。

标签临近内容圆角时使用连续桥接曲线，外观仍在试用；旧圆角断言的待处理范围见 [记录](verification-log/2026-10.md#临近圆角的连接过渡2026-10-26)。

横向首标签齐边、横竖裁切端部与接缝渐隐已调整，见 [本轮记录](verification-log/2026-10.md#标签齐边与接缝渐隐2026-10-26)。

普通标签与独立置顶标签现可分别设置行数显示方式，共用展开区域；边界滚动保护与新建入口细节已接入。相关离屏检查和部署结果见 [本轮记录](verification-log/2026-10.md#独立标签行与共享展开区域2026-10-26)，桌面测试与外观验收仍待恢复。

下表描述当前代码的行为，不记录变化经过；每一轮的修订说明和验证记录见 [验证日志](verification-log/2026-10.md)，完整交互要求见各设计文档。

| 范围 | 当前实现 |
| --- | --- |
| 模块 API | `WindowManager` 提供窗口、内容接入、布局、命令及内容显隐通知接口；`LayoutModel` 独立维护布局及不变量，带标签、窗格、分割节点的反向索引。未显示过的标签保留宿主内容但按需创建页面视图。窗口模块不依赖 Lua 或 Muxora 业务，独立构建与安装后的外部宿主夹具验证复用 |
| 标签与分割 | 中央区域可拆成多个标签组，每个标签内部可继续拆分窗格，分别导航与调整大小；组、标签、窗格之间可移动、交换、合并和层级转换，内容实例与 Pane ID 保持。布局变化只重建变化的部分 |
| 标签条 | 自绘标签栏（[标签栏设计](../design/tab-strip-design.md)）：上、下、左、右四种位置，竖向时可拖动宽度、收成图标并悬停展开；多行可平时收起，行尾计数块展开，推开内容或浮层两种方式；细滚动条盖在标签上，滚轮滚动，拖到两端自动滚动；完整列表；颜色预设只作底色，图标、编号和六种排序；可配置长标题裁切，普通／固定标签栏与非固定收纳条独立设置；关闭按钮不占位置，悬停时渐显；中键关闭；置顶标签排在最前，可设为紧凑或收缩尺寸，单行滚动时留在开头，也可单独占一行并单独滚动，默认关闭快捷键和中键不关闭它们；标签组可命名；标签夹可命名、着色、折叠和整夹拖动；新建按钮与类型菜单；右键可关闭左侧、右侧、其他或全部标签 |
| 四边停靠 | 标签可收纳到上下左右的收纳条，点击临时展开（逐标签记忆展开大小），也可固定占用空间；固定侧栏使用独立二维分割树，取消固定后再固定恢复原位置 |
| 两种窗口 | 默认拖出轻量浮窗，可升级为完整窗口、降级回轻量窗口；多个窗口组成逻辑窗口族，关闭和恢复按族处理 |
| 跨窗口移动 | 条内拖动时标签被提起、其他标签滑动让位，越过标签栏一定距离才拆出成浮窗；浮窗在桌面上由系统移动；回到标签栏时浮窗只留标签，目标内容区显示内容画面；放下位置决定置顶状态和所属标签夹；按指示或条带投放，经过内容区不误合并；轻量窗口标题栏可整窗拖动合并 |
| 工具区 | 顶部、底部工具区均支持多行、跨区拖动、末行投放预览和空行自动收起。工具条可显隐、压缩、增删按钮，每行一个弹性条带；弹性条带左侧的工具条以左边为固定端，右侧的以右边为固定端，拖动把手只改变固定端一侧那个工具条的宽度。压缩的菜单条把放不下的菜单列入溢出菜单，从溢出菜单打开时显示在它旁边 |
| 窗口控制 | 最小化、最大化、关闭三个按钮组成固定宽度（126 逻辑像素）的“窗口控制”工具条，可移动到任意行；按钮顺序可选 Windows、反向、macOS 三种。悬停最大化按钮显示 Windows 11 贴靠布局；最大化或全屏时，屏幕四角最外侧的像素都能点中最外侧的按钮（原因与取舍见 [ADR 0005](../adr/0005-caption-button-hit-testing.md)） |
| 显隐与全屏 | 工具区、全局状态栏、中央标签栏、四边收纳条各自独立显隐；窗口、标签组、窗格三种全屏；禅模式临时隐藏所有栏，可设置启动时自动进入的全屏范围；全屏和禅模式在退出程序后不恢复 |
| 命令与键盘 | 命令面板、窗口选择、标签组与窗格导航；快捷键支持二至四段续键、多条绑定、逐绑定参数、`runCommands` 顺序组合和按键查询，用户绑定保存在 `User/keybindings.json` |
| 输入法记忆 | 可在设置中选择记忆范围；焦点切到另一个范围时恢复其输入法和模式。Windows 实现及六种层级规则见 [输入法状态](../design/window-interaction-design.md#输入法状态)，实际输入状态只在本次运行中保留 |
| 菜单 | 主菜单为文件、视图、布局、窗口、工具、帮助；布局菜单按标签组、标签、窗格分层；轻量窗口有自己的局部菜单。菜单为方角，从触发控件左下方弹出 |
| 设置 | 可移动的设置标签，按类别排列并可搜索，分类树随滚动同步。下拉列表在默认选项的行尾标出“默认”。标题长度使用同排滑条与带上下微调的数字框，后缀为 `px`；输入和拖动时保留控件及焦点。滚轮不会修改或聚焦下拉框、数字框、日期时间框和滑块，而是滚动页面 |
| 提示 | 提示气泡使用当前主题，快速切换控件时大小不变；超过 400 逻辑像素的提示按形状换行，不会变成细长条 |
| 界面语言 | 跟随系统、简体中文、English；Qt 翻译随程序嵌入，选择保存在 `User/settings.json`，重启后生效 |
| Lua | 官方 Lua 5.5.1 随程序编译；用户启动脚本、命令与快捷键、工具条和状态项、窗口操作、事件和计时器。独立线程提供完整标准库、标准语义的 `require` 与协程宿主调用，模块顶层可直接调用 `muxora.*`；没有执行预算，保留显式停止和有界传输／队列。阻塞标准调用返回前不能中断，退出时限时等待；`os.exit` 走正常保存关闭流程，中文路径由 UTF-8 清单支持。范围见 [ADR 0008](../adr/0008-full-standard-library-for-local-scripts.md) 与 [Lua 指南](lua-guide.md) |
| 保存恢复 | 只恢复当前格式的严格 JSON 布局，由宿主通过 `QSaveFile` 原子写入；行为设置、正常几何和最大化状态、两种窗口各自的工具条布局及四栏偏好随布局保存；关闭最后一个窗口前同步保存；显式标题和标签配色原样恢复。恢复大量标签时只物化当前可见组，切换标签再创建对应页面视图 |
| 启动参数 | `--fresh` 从初始布局开始，`--state-dir <path>` 使用独立状态目录，`--command <id>` 执行已注册命令（例如 `muxora.exe --command window.settings`） |

占位内容（工作区、文件浏览、会话和传输区域）只用于试用布局，不代表真实连接。

布局状态默认位于 `QStandardPaths::StateLocation` 下的 `window-preview/window-layout.json`。程序自动合并短时间内的布局变化后保存；占位编辑器中的文字不会保存。通过命令面板选择“恢复初始工作区布局”，或启动 `muxora.exe --fresh`，可从初始布局重新试用；`--state-dir <path>` 可指定独立状态目录。
