# 界面审查（2026-10）

> 2026-10 整体审查的快照，不再更新；可执行步骤以 [实现计划](../implementation/README.md) 为准，说明见 [审查目录](README.md)。

日期：2026-10-19\
依据：[界面设计规范](../../design/ui-design-system.md)、[主题系统设计](../../design/theme-system-design.md)。本次审查根据源码逐项核对，没有在真实桌面上逐屏截图；实现阶段 8 时需在组件画廊和真实窗口中复核。行号对应提交 `01df918`。

整体判断：窗口系统的布局、停靠和层级能力已经很完整，但临时界面（弹窗、选择器、输入框）各自为政：有的是带表头和确定／取消按钮的居中对话框，有的是三层嵌套菜单，有的是 Qt 默认的 `QInputDialog`。外观、键盘行为和位置互不一致，也明显不同于 VS Code 和 Visual Studio。设置页和快捷键页信息密度高、层次弱。这些问题需要通过统一组件解决，而不是逐个美化。
